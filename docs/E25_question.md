## 불명확해서 정해야 하는 것

1. **연결이 무엇인가.** 컷 워크플로의 Load Image에 레퍼런스 Best 파일을 넣는 것인지, 프롬프트의 `@이름`인지, 컷에 레퍼런스 id 목록을 저장하는 것인지.
2. **v1과 v2의 차이.** v1이 `0.9.34` 매니저인지, FEATURES.md의 "Load Image에 넣기"인지, 아직 없는 1차 연결인지. v2가 그중 무엇을 바꾸는지.
3. **어떤 레퍼런스가 어떤 컷에 붙는지.** 컷마다 수동 선택인지, 이름·카테고리·캡션·프롬프트 토큰 일치인지.
4. **언제 반영되는지.** 워크플로를 열 때, Queue 할 때, 레퍼런스 이미지가 바뀔 때. 디스크의 컷 워크플로를 고치는지, 큐에 보내는 그래프만 고치는지.
5. **Load Image가 여러 개일 때.** `0.9.135` 시작 이미지는 가장 낮은 노드 id를 쓴다. 연결과 그 규칙이 같은지, 노드 제목·슬롯을 사용자가 고르는지.
6. **데이터.** 컷에 새 필드를 둘지, 기존 프로젝트는 비어 있는 연결로 둘지.
7. **UI.** 어느 화면에서 연결하고, 영어 라벨·토스트는 무엇인지. 사용자에게 보이는 텍스트에 native / gonggan을 쓰지 않는 규칙만 있다.
8. **범위.** 네이티브 프로젝트만인지, 읽기 전용 legacy import도인지.
9. **버전.** 체크리스트는 `0.9.139`인데 현재 브랜치는 `restore/0.9.137`이다. 버전 번호를 올릴지.
10. **Use AI.** 도움말의 reference linking이 이 기능이면, Use AI (Beta) OFF일 때 연결도 끄는지, 모델 호출이 필요한지.
